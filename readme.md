# Lattice — Mark Studio

Minimal browser-based QR code generator. Built by Reahoon.

## Features

- 6 content types: Link, Text, Wi-Fi, Email, Phone, Contact
- 4 module styles: Square, Soft, Dot, Diamond
- Custom colors + presets, center logo upload
- Export: SVG, PNG (256/512/1024px), copy image/payload
- History (10 items), dark mode, fully client-side

## Tech

- Vanilla JS, no build step
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)
- LocalStorage for history/theme

## Usage

Open `index.html` in any modern browser. Enter content → customize → download.

## Privacy

Everything runs in-browser. Nothing is uploaded.
